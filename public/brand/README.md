# Brand assets

- Calendar icon: original filled vector contours from the Aarhus Havn design manual, page 41, icon 01 “Kalender”. Translated into the shared 50×50 viewBox without redrawing. Used with descriptive date/time text, as required by the manual. Source contours live in `BrandIcon.tsx`.

- `aarhus-havn-wordmark.svg` is the official Aarhus Havn horizontal wordmark, preserved unchanged from the primary source: https://cdn.prod.website-files.com/664c5c4e2aed028ecda3e892/664c5c4e2aed028ecda3ebf0_aah_logo_horizontal.svg
- `aarhus-havn-stacked.svg` is the official stacked Aarhus Havn wordmark, normalized only in the source SVG's numeric precision: https://cdn.prod.website-files.com/664c5c4e2aed028ecda3e892/664c5c4e2aed028ecda3eb81_aah_logo%203.svg
- `port-access-horizon.webp` was generated with GPT Image on 2026-08-24 as a fictional representative harbor motif. It is illustrative, not live or actual Aarhus imagery.

- `aarhus-havn-monogram.png` is the official 32×32 RGBA favicon PNG, copied without redrawing, recolouring or re-encoding. Source: https://cdn.prod.website-files.com/65e8645ed4e5ccf7a0756056/6614f09bc9afc476caee4999_aah-favicon-32x32.png, linked by https://www.portofaarhus.dk/. It shows the white line on navy `#0A3055`; the design manual names the independent line “Linjen”. It is not the stacked wordmark. The sidebar and browser icon use the same asset path in `src/lib/brand.ts`. This does not assert whole-UI design-manual compliance.
